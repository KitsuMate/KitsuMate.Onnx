# Changelog

## [1.0.0] - 2026-07-11

- Added batched embedding requests, model identity, isolated runtimes, and LLM2Vec support.
- Removed live inference state and synchronous execution from engine assets.

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-05

### Added
- Initial release
- TextEmbeddingEngine for text embedding generation
- TextEmbeddingModelSet for embedding models
- Mean pooling and CLS pooling strategies
- Embedding normalization support
- Integration with tokenizers package
